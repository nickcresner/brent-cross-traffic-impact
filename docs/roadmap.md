# Delivery roadmap

## Foundation — completed

- [x] Define research question and community use cases.
- [x] Produce sourced, dated restriction map.
- [x] Document study protocol, assumptions and data requirements.
- [x] Add validated exploratory CSV-to-JSON analysis and automated tests.
- [x] Add synthetic time playback, time slider, point details and local JSON import.
- [x] Extend the animation basemap to a five-mile classified road network.

## Milestone 1 — acquire usable observations

- [ ] Obtain Traffic Stats access and verify trial, licensing and export limits.
- [ ] Obtain a small historical sample with coverage information.
- [ ] Request TfL's assessment, monitoring and works-phase register.
- [ ] Map observations to a stable segment network.
- [ ] Obtain a current complete road network and evaluate minor-road coverage.
- [ ] Audit dates, time zones, preparatory works and missing coverage.

Acceptance: reproducible, licensed input covering comparable periods and directions; missing data visible.

## Milestone 2 — measure and evaluate

- [ ] Publish observed deterioration by road, direction and time.
- [ ] Select controls and examine pre-work trends and diversion spillover.
- [ ] Retain repeated-period observations and add robust uncertainty estimation.
- [ ] Evaluate sensitivity to controls, baseline weeks and confounder exclusions.
- [ ] Validate against held-out periods and actual local journeys.

Acceptance: estimates carry coverage and uncertainty; unsupported causal conclusions suppressed.

## Milestone 3 — public map and journeys

- [ ] Add observation-period filters and separate observed/estimated layers.
- [ ] Show typical and bad-day journey times from route-level data.
- [ ] Add licensed live routing and arrival-time advice.
- [ ] Evaluate prediction error and achieved on-time arrival rates.
- [ ] Add opt-in alerts, with minimal personal-data retention.

Acceptance: accessible mobile experience, timestamps and stale-data handling; no promise of guaranteed arrival.

## Milestone 4 — ongoing portfolio case study

- [ ] Compare construction phases and investigate mitigation.
- [ ] Document methods, validation, limitations and design iterations.
- [ ] Publish a concise case study and reproducible permitted outputs.

Project duration is up to two years. Current restrictions must not be projected unchanged over that period.
